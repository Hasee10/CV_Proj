https://cullenwebber.github.io/three-volumetric-light/

## Francesco Michelini / Codrops - Interactive 3D Cluster

https://tympanus.net/Tutorials/3DCluster/
https://github.com/kekkorider/codrops-tutorial-dark-cluster

Reference for the extruded triangular shell, breathing facets and hover interaction. ClusterScene.tsx is an independent implementation in standard Three.js/WebGL, with original geometry-generation, lighting and interaction code. No upstream code or textures copied. The upstream repository does not declare a licence. Attribution does not assert permission to redistribute that repository's implementation.
