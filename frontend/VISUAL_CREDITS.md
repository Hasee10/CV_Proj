# Visual credits

## Cullen Webber - volumetric light

https://cullenwebber.github.io/three-volumetric-light/
https://github.com/cullenwebber/three-volumetric-light

The original hosted work is displayed in a sandboxed cross-origin iframe, with credit. No source code, hand model, fonts or shader files were copied. Availability and performance of this scene depend on the external host. The scene is a credited third-party artwork, not a student-created model or a visualisation of the recognition backend.

## Franky Hung / Arkon Digital - Wavy Cubes

https://projects.arkon.digital/threejs/wavy-cubes/

Current hero reference: full-surface pale cube tiles, depth waves and pointer highlighting. WaveGridScene.tsx is an independent local Three.js implementation with instanced geometry and original lighting/interaction code. No upstream source or assets copied. Replaces the earlier Codrops cluster.

## Dmytro Barylo - LeafThrough

https://github.com/dmtrbrl/leafthrough
https://dmtrbrl.github.io/leafthrough/

Actual MIT-licensed package integration: leafthrough 0.1.8. The complete MIT notice is retained in public/leafthrough-license.txt and served with the application. The six booklet pages are original vector artwork and project text; the SVG generator is committed. Scientific descriptions follow the frozen project handover and do not introduce new benchmark numbers.

Implementation assisted by Codex. References and authorship remain distinguished from project work.
